# Proyecto de Ventas
Página web para productos y ventas basada en un diagrama E-R.
Incluye inicio de sesión y registro en la base de datos, y CRUD completo de cada entidad.

## Paleta de Colores
#### ![](https://placehold.co/10/2560b3/2560b3.png) #2560b3
Color principal para títulos y botones de acción. Refleja confianza y seguridad.

#### ![](https://placehold.co/10/ebf4ff/ebf4ff.png) #ebf4ff
Resalta el objeto con el que se está interactuando sin generar molestia visual.

#### ![](https://placehold.co/10/3e3e4f/3e3e4f.png) #3e3e4f
Color de fondo. Crea contraste con los contenedores blancos, enfocando la atención.

#### ![](https://placehold.co/10/616161/616161.png) #616161
Subtítulos y botones de navegación. No es completamente negro, evitando cansancio visual.

#### ![](https://placehold.co/10/ffffff/ffffff.png) #ffffff
Contenedores. Atrae la vista. Hace que la interfaz se sienta limpia y organizada.

#### ![](https://placehold.co/10/f03535/f03535.png) #f03535
Botones de eliminar/cancelar y mensajes de error. Indican precaución y acciones irreversibles.
